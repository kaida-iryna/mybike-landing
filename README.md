# MyBike Landing Page

A responsive landing page for an urban bike store featuring bike models,
descriptions, prices and contact information.

## Live Preview

[View the website](https://kaida-iryna.github.io/mybike-landing/)

## Design Reference

[Figma mockup](https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0-1&p=f&t=EfhKfzCa7bvquLFf-0)

## Technologies Used

- **HTML5** — semantic markup
- **SCSS** — variables, mixins, nesting, BEM methodology
- **JavaScript** — smooth scrolling navigation
- **Parcel** — bundler and dev server
- **ESLint / Stylelint / LintHTML** — code quality

## Getting Started

Clone the repository and move into the project folder:

```bash
git clone https://github.com/kaida-iryna/mybike-landing.git
cd mybike-landing
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The page will be available at [http://localhost:8080](http://localhost:8080).

Other available commands:

```bash
npm run lint    # check HTML, SCSS and JS
npm run build   # build the production bundle
npm run deploy  # publish to GitHub Pages
```

## Features

- Fully responsive layout with breakpoints at 576px (tablet) and 1024px (desktop)
- Burger menu with a full-screen navigation overlay
- Smooth scrolling between sections
- Hover effects on interactive elements
